# What did I learn

### Custom Exceptions
In this program I used the OutOfBounds, and SelfContact exceptions as a way to end the game and prevent it from starting again until the game is asked to restart
now a better way of ending the game would be to have change a variable called "gameOver", but to be honest I just wanted to experiment with custom exceptions

### Enums
Ive had a very basic understanding of enums for a while, but I couldn't find a use for them.
in this project i used enums to set the type of object present in the world, and to set the possible player directions (which i realize prolly was a waste but i was having fun)

### Main Take Aways
Overall I built a basic world that can contain the player, and apples (with stuff built in so i have the options to add blocks later).
Over the course of this project i learnt how to use singleton classes/variable, aswell as building a renderable world that contains all the world objects. From my near 0 experiance with javax.swing to rendering a moving player and objects in the world i cant be mad
